# Фабрика "KS"

Android-приложение фабрики (Kotlin, Jetpack Compose, Material 3): коммерческие предложения, счета, договоры,
оплаты и долги, заказы на производство, склад пряжи, расход пряжи и калькулятор.

## Возможности

- Цифры, `+ − × ÷`, десятичная запятая, смена знака `±`, процент `%`, скобки `( )`.
- Длинные выражения с приоритетом операций, предварительный результат при наборе.
- Удаление последнего символа (⌫), полная очистка (AC), обработка деления на ноль и некорректных выражений.
- История вычислений (до 100 записей) хранится только на устройстве: вернуть запись в калькулятор, скопировать результат, очистить историю.
- Аппаратная клавиатура: `0–9`, `. ,`, `+ - * /`, `%`, `( )`, `Enter`/`=`, `Backspace`, `Esc`/`Delete`.
- Тёмная (палитра Knit ERP) и светлая темы; переключатель: «как в системе» → светлая → тёмная.
- Кнопка «Скопировать результат» под дисплеем (или удержание на дисплее).
- **Расход пряжи** (значок клубка вверху): см. раздел ниже.
- Калькулятор и расход пряжи работают без интернета. Интернет используется только для связи с вашей Google Таблицей
  (справочники и КП); письма отправляет выбранное вами почтовое приложение; резервное копирование данных отключено.

## Учёт (v1.3)

- **Оплаты и долги** — долг по каждой согласованной сделке, внесение оплат, счета; полная оплата → статус «Оплачено».
- **Счёт на оплату** (История КП → «⋮») — предоплата / остаток / вся сумма, банковские реквизиты, сумма прописью.
- **Договор поставки** — текст из листа «Договор» таблицы, спецификация из КП, реквизиты сторон.
- **Производство** — заказ из КП, срок в рабочих днях, версионные техкарты и маршрут операций; пряжа списывается при переходе в вязку.
- **Склад пряжи** — приход/расход в кг, остатки, нехватка на новые заказы.
- **Прайс-лист PDF и QR-код** — в «Ассортименте»; QR-код страницы сайта — в «Каталоге на сайте».
- **Режим директора** — «PIN директора» в листе «Настройки»: менеджеры не видят себестоимость и прибыль.
- Документы отправляются клиенту письмом через Google-скрипт (ответ и копия — на e-mail фабрики) или через «Поделиться».

## МойСклад (v1.4)

МойСклад — главный учёт, приложение — быстрый фронт менеджера. Подключение: в Google Таблице меню
«Фабрика KS → Подключить МойСклад…» и токен пользователя «Приложение KS» (токен хранится в свойствах скрипта).

- **Товары** с ценами по тиражам (типы цен «1 штук / 10 / 20 / 50 / от 100 / от 500 штук») и остатком склада
  «Электросталь»; выбор — поиск по названию/артикулу и группе. Изделия «под заказ» — калькулятор из таблицы.
- **Клиенты** МойСклад — в подсказках; новый клиент из КП создаётся по ИНН.
- **КП → «Заказ покупателя»** («КП-№»), статусы КП — статусы заказа; **счёт → «Счёт покупателю»** (номер из МойСклад);
  **оплата → «Входящий платёж»**; долги — по оплаченной сумме заказов МойСклад.
- Себестоимость в экономике КП — закупочная цена товара.

## Производство: первый срез единого ТЗ

Сервер поддерживает технологические карты с черновиками и утверждёнными версиями. Производственному заданию
назначается конкретная утверждённая версия, а её полный снимок сохраняется вместе с заданием. Поэтому последующее
изменение техкарты не меняет уже начатое производство.

- маршрут содержит упорядоченные операции, норму времени, признак обязательности оборудования и QR-код операции;
- вязание автоматически требует оборудование, а выпуск разрешён только на последней операции;
- следующий обязательный этап получает не больше количества, завершённого на предыдущем обязательном этапе;
- этап вне утверждённого маршрута запустить нельзя;
- после начала работ заменить техкарту задания нельзя;
- задания без техкарты продолжают работать по прежней схеме, чтобы обновление не ломало действующее производство.

API сервера: `techCards`, `techCardSave`, `techCardApprove`, `jobTechCardAssign`. В ответе `jobs` закреплённый
снимок приходит в поле `techCard`; Android-экран производства показывает код и версию карты.

## Расход пряжи

- Ввод: изделие, номер заказа, вес одного изделия (г), заказ в штуках **или** в кг готовых изделий, % брака.
- Состав: основная нить + любое число доп. нитей (Доп 1, Доп 2, …, спандекс/резинка) с долями в %.
  Доля основной нити = 100 % − сумма доп. нитей. Однотонное изделие — только основная нить.
- Расход с браком = вес изделия × доля × (1 + брак/100); итог по каждой нити в г/шт и в кг на заказ.
- Отчёт PDF (A4): «PDF» — отправить/сохранить через меню «Поделиться», «На почту» — письмо с вложением
  на BasilSolanji@Gmail.com (адрес можно изменить в почтовом приложении), «Печать» — принтер или «Сохранить как PDF»,
  «Копировать» — текстовая сводка. Форма сохраняется на устройстве.

## Коммерческое предложение (КП)

Значок документа вверху калькулятора.

- **Позиции:** изделие из ассортимента → параметры (ширина/размер, рисунок, цвет…) → количество.
  Цена за единицу = базовая цена + надбавки выбранных вариантов − скидка от количества;
  сумма = цена × количество + разовая подготовка. Предупреждение, если меньше минимального заказа.
- **Ассортимент и цены** (значок списка): подвязы, воротники поло, манжеты — стартовые позиции с
  ориентировочными ценами. Можно менять цены, параметры, надбавки, скидки, минимальный заказ,
  добавлять свои изделия (шнуры, бейка и т. д.), удалять и менять порядок.
- **Реквизиты фабрики** (значок шестерёнки): Фабрика «KS», г. Электросталь,
  ООО «Солвер», ИНН 9705239429, +7 985 000-79-92, Sale@fabrika-ks.ru; НДС 22 % (цены с НДС или
  НДС сверху), срок действия КП 5 дней, срок изготовления, условия, подпись — всё редактируется.
- **PDF КП (A4)** от имени команды Фабрики «KS»: «PDF» (поделиться/сохранить), «На почту»
  (письмо клиенту с вложением), «Печать», «Копировать». «Новое КП» увеличивает номер.

## Google Таблица: общие справочники и КП для нескольких телефонов

Таблица «Knit ERP — справочники и КП Фабрики KS» (Google Диск владельца) содержит листы:

| Лист | Что в нём |
|---|---|
| Изделия | Код, название, ед., базовая цена, мин. заказ, подготовка, шаг округления, активно |
| Параметры | Код изделия, параметр, вариант, коэффициент (`1,04`, `13/14`, `1,04*1,04`), надбавка ₽ |
| Объём | Код изделия, «от количества», коэффициент (`1,07*1,03*1,22`) |
| Настройки | Реквизиты, НДС 22 %, срок действия КП, срок изготовления 5–15 раб. дней, бесплатная доставка от суммы, ключ доступа |
| КП / Позиции КП | Сохранённые КП (номер, дата, клиент, суммы, менеджер) и их позиции |
| Инструкция | Как подключить и код скрипта |

Система цен подвязов повторяет «Прайс-лист подвязов KS»: 170 ₽ за 115×14 → коэффициент объёма →
× ширина/14 → тип нити (+4 % на ступень), с округлением до рубля после каждого шага
(тест сверяет все 192 цены прайса).

Связь — через веб-приложение Google Apps Script (`google-sheets/Code.gs`): приложение читает справочники,
а при отправке КП сохраняет его в таблицу и получает следующий номер (под блокировкой, без повторов).
Без связи используется последняя загруженная копия справочников.

## Правила вычислений

| Правило | Пример |
|---|---|
| Приоритет: скобки → унарный минус → `%` → `× ÷` → `+ −` | `2+3×4 = 14` |
| `a + b%` / `a − b%` — процент от `a` | `200+10% = 220` |
| В остальных случаях `b% = b/100` | `200×10% = 20`, `50% = 0,5` |
| Незакрытые скобки закрываются при вычислении | `(2+3 = 5` |
| Точная десятичная арифметика (`BigDecimal`, 34 знака), результат округляется до 15 значащих цифр (половина — вверх) | `0,1+0,2 = 0,3`, `2÷3 = 0,666666666666667` |
| Числа ≥ 10¹⁵ и < 10⁻⁹ — в экспоненциальной записи | `1E20` |

Вычисление выполняет собственный парсер (рекурсивный спуск) — произвольный код не выполняется.

## Структура

- `core/` — чистый Kotlin: парсер и вычислитель (`Evaluator`), логика ввода (`CalculatorEngine`), форматирование (`NumberFormatter`) и unit-тесты.
- `app/` — Android-приложение: Compose-интерфейс, `CalculatorViewModel` (состояние переживает поворот и пересоздание Activity через `SavedStateHandle`), локальная история.

## Сборка

Требуется JDK 17 и Android SDK (compileSdk 35). minSdk 24 (Android 7.0+).

```bash
./gradlew test             # unit-тесты
./gradlew assembleDebug    # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease  # app/build/outputs/apk/release/app-release.apk (R8)
```

GitHub Actions (`.github/workflows/android.yml`) на каждый push запускает тесты, lint и сборку,
а готовые APK публикует как артефакт **KnitCalculator-apk** на странице запуска workflow.

## Установка на телефон

1. Скачайте `KnitCalculator-release.apk` (быстрее и меньше) или `KnitCalculator-debug.apk`.
2. На телефоне разрешите установку из этого источника (Настройки → Безопасность → «Установка неизвестных приложений»).
3. Откройте APK и подтвердите установку. Либо по USB: `adb install -r KnitCalculator-release.apk`.

> Подпись: если в репозитории заданы секреты `KS_KEYSTORE_BASE64` и `KS_KEYSTORE_PASSWORD`, CI подписывает APK
> постоянным ключом фабрики — новые версии ставятся поверх. Без секретов — одноразовый отладочный ключ.
