# Граница MVP 1.0

Источник: ТЗ §1.34 (KA3235–KA3243), §1.36 (KA3313). Это первый рабочий срез единой knitERP, а не отдельная складская программа.

## Входит
- Организация, реквизиты, площадки, подразделения, должности, сотрудники, статусы занятости.
- Пользователи, роли, серверные права, области данных, отзыв доступа, журнал входов. Матрица прав P0 (§69).
- Номенклатура, типы, единицы, контрагенты, склады, причины операций, импорт и архивирование.
- Начальные остатки, поступление, перемещение, списание, инвентаризация, остатки и движения.
- Статусы, проведение, отмена, закрытый период, аудит, конфликт редактирования, сверка.
- Шаблонный импорт и экспорт основных данных, протокол ошибок, контрольные итоги.
- Отчёты: остатки, движения, обороты, отклонения инвентаризации, базовые реестры.
- Раздельные среды, выпуск, резервные копии, восстановление, мониторинг, инструкции.

## Не входит
Зарплата и кадровый ЭДО, рейтинг сотрудников, полное производственное планирование, фактическая себестоимость, УПД/ЭДО, клиентский кабинет, мобильное приложение, маркетплейсы, 1С и банки, BI, микросервисы.

## Под вопросом (D01, D02, D18)
Смены, принятие работ и базовые техкарты: источник Б относит их к P1 перед складом, источник A — после первого запуска. До решения владельца продукта разработка идёт по порядку источника A (§14.41): организация → права → сотрудники → структура → номенклатура → склады → остатки → документы → инвентаризация → отчёты.
