# knitERP — правила для работы в этой папке

Источник требований: «knitERP — объединённая редакция требований» от 09.10.2026 (источники A v2.3 и Б v1.21). Идентификаторы блоков KAxxxx/KBxxxx и вопросы D01–D22 ссылаются на этот документ.

## Стек и архитектура
- C# / .NET 10, ASP.NET Core, Blazor Web App, EF Core 10, Microsoft SQL Server. Модульный монолит (ADR-0001).
- Слои: Domain (без зависимостей) → Application (сценарии, проверка прав) → Infrastructure (EF Core, SQL Server) → Web.
- Микросервисы, Kubernetes, шина сообщений, отдельный SPA — вне первого контура (KA2621, KA2686).

## Граница работы
- MVP 1.0 — только то, что перечислено в `docs/mvp-scope.md`. Новая функция входит в MVP только с исключением равноценной (KA2929).
- Открытые вопросы — в `docs/decisions.md`. Рабочее допущение помечается в коде комментарием `// Допущение Dxx` и не выдаётся за решение заказчика.

## Обязательные правила кода
- Запрет по умолчанию: каждое действие проверяет право на сервере (`IAccessGuard.DemandAsync`). Скрытая кнопка — не защита.
- OrganizationId берётся из контекста пользователя, а не из запроса. Чужая организация → 404, не 403.
- Запрет сильнее разрешения. Нельзя выдать право выше своего. Нельзя оставить организацию без активного Владельца.
- Ключи bigint identity; GUID только для внешних идентификаторов. Время — UTC в `datetime2(3)`. Деньги `decimal(19,4)`, количества `decimal(18,6)`.
- `rowversion` на изменяемых сущностях; конфликт возвращается пользователю.
- Документы и движения физически не удаляются, справочники архивируются. Журнал аудита только на вставку.
- FK, UNIQUE и CHECK создаются в SQL Server, а не только в интерфейсе.
- Применённые миграции не редактируются — только новая корректирующая.
- Никаких паролей, ключей и реальных персональных данных в репозитории и тестах.

## Порядок одной функции (KA2665)
1. Сценарий, состояния, негативные случаи → 2. сущности и миграция → 3. сервис и транзакция → 4. права и правила на сервере → 5. Blazor-форма → 6. аудит и лог → 7. тесты → 8. проверка на тестовой базе фабрики.
